## Important
This version is a functional local prototype. Data is stored in browser localStorage.

For a real multi-device private deployment:
1. Create a Firebase project.
2. Enable Firebase Authentication.
3. Create Firestore.
4. Replace the demo login with Firebase Auth.
5. Add role-based Firestore Security Rules.
6. Add QR scanning and audit-log protection.
7. Deploy with Firebase Hosting.

Do NOT use the demo credentials in production.
